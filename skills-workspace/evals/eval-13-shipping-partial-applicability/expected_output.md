An example table where Express shipping is split by the UK free-tier rule. Value sets should be used to consolidate rows with the same outcome — e.g. Express non-UK rows at/above threshold into one row, Overnight UK and Ireland into one row. Standard uses a value set for destination (all options produce the same result). Inferring 'International' as a third destination is reasonable. Unavailable shipping methods use blank output cells (not 'N/A' or '-').
