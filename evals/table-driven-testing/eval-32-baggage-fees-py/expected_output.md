Parametrized pytest tests enumerating the full fee ladder: every fee tier (included, heavy, oversize) is represented, and every boundary (23, 32, 45 kg) is tested from both sides — including the middle-tier boundaries that boundary-sampling tends to skip. Scenario ids describe conditions ("at included limit", "just over heavy limit"), not outcomes. The not-accepted case is its own test using pytest.raises, not mixed into the fee table via sentinel values or branching. Values are concrete domain values (weights in kg, fees in euros).
